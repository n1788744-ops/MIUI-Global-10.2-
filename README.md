# MIUI 10 OS (MIUI Global 10.2)

Оболочка и рабочий стол в стиле MIUI Global 10.2 с профилем **256 МБ ОЗУ**, выделенной памятью для фоновых процессов оптимизации (**64 МБ**) и поддержкой процессора от **1.5 ГГц** для плавности интерфейса.

## Скачать готовый APK

- **[Скачать MIUI-10-OS.apk](./releases/MIUI-10-OS.apk)** (собранный и подписанный APK в папке `releases/`)

На странице файла на GitHub нажмите кнопку **Download raw file** (или **Raw**), чтобы скачать `.apk` на телефон и установить.

## Основные возможности

- **Первый запуск**: запрос системных разрешений и назначение рабочим столом по умолчанию (`HOME` launcher).
- **Рабочий стол MIUI 10.2**: поиск Google, крупные часы и дата, сетка приложений (`Браузер`, `Галерея`, `Настройки`, `Музыка`, `Google`, `Безопасность`, `Инструменты`, `Play Маркет`), док-панель и вторая страница со всеми установленными приложениями устройства.
- **Шторка управления**: свайп вниз открывает быстрые переключатели (`Wi-Fi`, `Фонарик`, `Bluetooth`, `Автояркость`, `Блокировка`, `GPS`, `Режим чтения`, `ОЗУ 256 МБ`, `ЦП ≥1.5 ГГц`) и регулировку яркости.
- **Настройки и Безопасность**: мониторинг ОЗУ 256 МБ, буфера фоновой оптимизации и частоты ЦП от 1.5 ГГц в реальном времени.
